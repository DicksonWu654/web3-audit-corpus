For coding agents: clone the findings

Every finding as a plain Markdown file, with the report extracts, linked hub pages by firm, class, language, chain and project, and a metadata graph. Open the folder in Claude Code or Codex; its AGENTS.md tells the agent how to search.

Only need one firm or class? A sparse clone works; the repository README has the commands.

git clone --depth 1 {{data_repo}}
cd web3-audit-findings

For notebooks and bulk queries: release files

  • audits-markdown.zip{{db.size_markdown}}

    One Markdown file per report, every finding a section, in one download.

  • findings.parquet{{db.size_parquet}}

    The findings table for DuckDB, pandas or Polars. Join it to engagements.csv and reports.csv.

  • findings.jsonl.gz{{db.size_jsonl}}

    One JSON object per finding, with firm, project, year and the original report link. For scripts and jq.

  • findings.csv.gz{{db.size_csv}}

    The same table as compressed CSV, for spreadsheets and anything else.
