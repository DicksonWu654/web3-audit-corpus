# v1.3.0: database edition

Web3 Audit Corpus ships as a downloadable database of audits and findings for code review and auditing work. The research analysis follows separately.

The 2026-10-22 snapshot contains 63 publishers, 12,767 industry engagements, 13,522 report files, 11,027 distinct project names and 175,640 finding records. Of those records, 160,239 have full text. Audit years span 2015 to 2026; 2026 is year to date.

- Added `audits-markdown.zip`: one file per report, with metadata, source links and available finding text, plus `README.md` and `INDEX.csv`.
- Added `findings.jsonl.gz`: one object per finding, joined to audit and publisher metadata.
- Added the [agent guide](../AGENTS_GUIDE.md) with local setup, SQL examples and auditing prompts.
- Made the public documentation database-first and limited `stats.zip` to descriptive tables.
- Preserved the existing Parquet, CSV, taxonomy and provenance assets. Regenerated the dictionary, statistics schema and checksums for this edition.

Both new formats preserve attribution and licence fields. Withheld or unavailable bodies remain absent. AI-assisted extraction may contain errors; always check the linked original. Derived metadata is CC BY 4.0, and publisher text retains its own rights.
